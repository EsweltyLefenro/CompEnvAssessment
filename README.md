
# CompEnvAssessment — Enterprise Competitiveness Assessment

**CompEnvAssessment** — настольное приложение на C# / WPF для оценки конкурентоспособности предприятия на основе взвешенных факторов, сравнения с конкурентами и построения карт стратегической группировки.

Проект разрабатывается как развитие [ExtEnvAnalysis](https://github.com/EsweltyLefenro/ExtEnvAnalysis) — программного средства, созданного в рамках выпускной квалификационной работы 2026 года.

## Текущие возможности

- Ввод информации о пользователе и анализируемом предприятии.
- Добавление факторов конкурентоспособности и назначение их весов.
- Оценка предприятия и конкурентов по шкале от 1 до 10.
- Автоматический расчёт взвешенных рейтингов.
- Построение карт стратегической группировки по парам факторов.
- Формирование промежуточных и итоговых аналитических выводов.
- Генерация PDF-отчёта.
- Демонстрационный режим преподавателя.

## Технологии

- **C# / .NET 8**
- **WPF / XAML**
- **MVVM / CommunityToolkit.Mvvm**
- **QuestPDF**

## Запуск

**Требования:** Windows и .NET 8 SDK.

```bash
git clone https://github.com/EsweltyLefenro/CompEnvAssessment.git
cd CompEnvAssessment
dotnet run --project CompEnvAssessment/CompEnvAssessment.csproj
```
